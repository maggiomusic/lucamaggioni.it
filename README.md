Preparazione sito - lucamaggioni.it

Istruzioni rapide:

- Apri `index.html` nella cartella del progetto per vedere la pagina (browser locale).
- Le immagini locali si trovano in `img/`. In particolare: `img/luca-img-sfondo.png`.
- Se vuoi servire il sito localmente con un semplice server (consigliato):

  ```bash
  # dalla cartella lucamaggioni.it
  python3 -m http.server 8000
  # poi apri http://localhost:8000
  ```

Note:
- Ho copiato `lucamaggioni_remake.html` come `index.html` e aggiornato il percorso della seconda immagine dell'hero a `img/Luca img sfondo.png`.
- Se preferisci rimuovere gli spazi nel nome file, posso rinominarlo automaticamente e aggiornare i riferimenti.
